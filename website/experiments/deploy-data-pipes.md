## The idea | An agentic workflow for deploying OHS FHIR Data Pipes

- A skill built on the existing FHIR Data Pipes APIs and documentation.
- Lets an agent take a team from zero to a working analytics pipeline.

## Status | Looking for collaborators

This idea is listed in the [OHS Labs backlog](https://github.com/ohs-foundation/ohs-labs#ideas-not-started-yet)
and hasn't started. If you'd like to own it, or have data or a deployment where
