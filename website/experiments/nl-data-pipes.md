## The idea | Natural language querying of the OHS FHIR Data Pipes warehouse

- Skills read the FHIR Implementation Guide or configs for context.
- The agent builds the query and enforces guardrails, e.g. no DELETE.
- MCP handles the database layer, possibly packaged as a workflow.

## Status | Looking for collaborators

This idea is listed in the [OHS Labs backlog](https://github.com/ohs-foundation/ohs-labs#ideas-not-started-yet)
and hasn't started. If you'd like to own it, or have data or a deployment where
it would help, get in touch.
